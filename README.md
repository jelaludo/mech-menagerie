# Mech Menagerie: display site

https://jelaludo.github.io/mech-menagerie/

The public, display-only copy of Jelaludo's 3D models: game assets built by script in Blender. The viewers show reduced copies (levels of detail 2 and 3, 2K textures); the full-detail models are sold separately.
